# Contract: Level content file (`data/levels.json`)

Validated in full by `engine/content.js` before anything is shown (FR-023, C6). Field rules are in
[../data-model.md](../data-model.md).

```json
{
  "schemaVersion": 1,
  "sources":       [ { "id", "title", "url", "section", "claim" } ],
  "switchClasses": [ { "id", "label", "maxPortMbps", "devicePorts", "uplinkMbps", "maxUplinks", "roles" } ],
  "deviceTypes":   [ { "id", "label", "portMbps", "upMbps", "downMbps", "shape" } ],
  "messages":      { "<reasonCode or 'rule'>": "fixed explanation text with {placeholders}" },
  "levels": [ {
    "id", "title", "outcome", "sourceIds",
    "briefing": { "concept", "terms", "workedExample", "simplifications" },
    "rounds": [ {
      "id", "intro",
      "start":        { "aggregation": {...}, "accessSwitches": [ {..., "deviceGroups": [...] } ] },
      "addedSwitches": [ { "id", "label", "classId", "activeUplinks", "deviceGroups": [...] } ],
      "addedDevices": [ { "switchId", "deviceTypeId", "count" } ],
      "allowedUpgrades": [ "uplinks", "replace" ],
      "claims":       { "uplinkOnly": false, "requiresClassChange": true },
      "hints":        [ "method …", "worked step …" ],
      "reference":    { "<switchId>": { "classId", "activeUplinks" } }
    } ]
  } ]
}
```

## Validation result

```text
validateContent(doc) → { ok: true, catalog, levels } | { ok: false, errors: [{ levelId?, roundId?, path, message }] }
```

The validator rejects the file (content-error screen naming level/round; nothing graded) when any
of these hold:

1. Structural: missing/extra-typed field, duplicate id, dangling reference (source, class,
   device type, switch), `schemaVersion ≠ 1`.
2. Model: a message missing for `rule` or any reasonCode / invalid-input code; not exactly 3 switch classes; 3 levels × 2 rounds not met; demand > port speed; device
   count > `devicePorts`; class/role mismatch; uplinks out of range.
3. Teaching: round start has no violation; reference does not pass or uses an upgrade type not in
   `allowedUpgrades`; Level 1 round allows `replace`; `claims` contradicted by
   exhaustive search over the allowed upgrade types (research R9); worked example equals a round start; fewer or more than 2
   hints; level with no source.
4. Continuity: `round[n].start` ≠ previous reference applied + `addedSwitches` + `addedDevices`
   (FR-014); more than 3 access switches.

Expected values in tests are written by hand from the spec. They are never generated by calling
`evaluate`.
